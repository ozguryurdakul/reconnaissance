Session Manager
Save your work or load files from other inspectors
💾
Save Session
Exports all your records and photos into a single .fieldsurveyjson file on your device. Use this at the end of each field day to back up your work and share with the team coordinator.
📂
Load & Merge
Loads a .fieldsurveyjson file and adds its records to your existing ones. Records that already exist (same ID) are skipped — no duplicates.
✅ Use this when combining files from multiple inspectors at end of day. Load each inspector's file one by one — all records accumulate safely.
🔄
Load & Replace
Loads a .fieldsurveyjson file and deletes all current records first, then loads the file fresh.
⚠️ Use this when restoring a known good session on a fresh device, or when you want to start clean from a saved file. All current records will be permanently deleted before loading.
